# MASTER_CLEANING_01

청소·홈케어 마스터. **현장에 찾아가는 생활서비스 업체**를 위한 판매용 원페이지입니다.

미리보기 → <https://v0125v0125-design.github.io/website-factory/cleaning-01/>
(가상 업체 `바른결 홈케어` 견본 · 검색 노출 차단)

```
templates/master-cleaning-01/
  template.json          섹션 차례와 업종·기능 태그
  index.html             base.html 을 상속만 한다
  partials/              머리 · 첫화면 · 약속 · 서비스 · 왜우리 · 전후 · 사례 ·
                         진행 · 지역 · 후기 · 질문 · 견적 · 바닥 · 스크립트
  assets/styles.css.j2   색은 전부 토큰에서. 고객이 바뀌면 토큰만 바뀐다
examples/customers/d-bareungyeol.json   가상 업체 주문서
examples/photos/cleaning/               직접 그린 견본 그림 20장
tools/make_cleaning_photos.py           그 그림을 다시 그리는 도구
```

## 1. 이 마스터로 파는 업종

**1차** — 입주청소 · 이사청소 · 거주청소 · 상가/사무실 청소

**데이터만 바꿔 재사용** — 에어컨청소 · 소파/매트리스 청소 · 홈케어 · 방역 ·
줄눈 · 유리청소 · 특수청소 · 정기청소

특정 "입주청소 업체 하나"가 아니라 **현장 방문형 생활서비스 업체용 판매 마스터**입니다.
업종을 바꿀 때 손대는 곳은 `services[]` · `projects[]` · `faq[]` · `seo` 네 군데뿐입니다.

봤지만 **하나는 접근 제한, 하나는 페이지 없음**이었습니다. 보지 못했으므로 분석에 넣지
않았습니다.

### 가져온 것

- **문의 행동을 항상 가까이 둔다.** 두 곳 모두 화면 어디에 있든 상담 버튼이 보입니다.
- **가격을 숫자로 못 박지 않는다.** 현장마다 다르므로 "견적"으로 받습니다.
- **서비스 갈래를 초반에 보여 준다.** 방문자가 자기 경우를 먼저 찾습니다.
- **FAQ 로 불안을 미리 끈다.** 시간·약품·추가비용·재방문이 실제로 걸리는 질문입니다.

### 버린 것

- **오른쪽 세로 플로팅 레일.** 둘 다 씁니다. 칸이 4~6개까지 늘어나 화면을 먹고,
  2010년대 홈페이지 인상을 줍니다. 여기서는 **머리에 전화·견적을 붙박이로 두고,
  좁은 화면에서만 하단 바**로 내립니다.
- **히어로 자동 슬라이드.** 세 장이 돌아가는 동안 방문자는 읽지 못합니다.
- **검증할 수 없는 신뢰 배지.** 배상보험 금액·인증서·파트너사 로고는 실제 고객이
  자료를 줄 때만 넣습니다. 견본에는 넣지 않습니다.
- **별 5개가 박힌 후기 벽.** 숫자가 아니라 무슨 작업이었는지를 적습니다.
- **과한 혜택 문구.** "5가지 특별 혜택 무료" 류는 쓰지 않습니다.

## 3. 인테리어 마스터와 무엇이 다른가

두 업종은 사는 이유가 다릅니다. 인테리어는 **결과 이미지**를 사고, 청소는 **불안 해소**를
삽니다. 그래서 색만 바꾼 같은 화면이 될 수 없습니다.

| | MASTER_INTERIOR_01 | MASTER_CLEANING_01 |
| --- | --- | --- |
| 머리 | 첫 화면 위에서 투명, 내려가면 흰색 | 처음부터 흰색 · **지역 칩 + 전화번호 붙박이** |
| 첫 화면 | 사진이 화면을 덮고 글씨를 얹음 | **왼쪽 글 / 오른쪽 사진 카드** · 사진 아래 지역·상담시간 |
| 두 번째 칸 | 큰 숫자 4개 (1,240건 · 6팀 · 2년) | **숫자 없는 약속 4줄** — 셀 실적이 없으므로 세우지 않음 |
| 서비스 | 사진 카드 격자 | **포함 범위 체크리스트가 먼저 읽히는 카드** |
| 핵심 시각 | 시공 사례 모자이크 + 크게 보기 | **작업 전·후 비교 손잡이** |
| 사례 | 큰 모자이크 · 분류 필터 · 라이트박스 | 작은 3열 격자, 훑고 지나가는 자리 |
| 지역 | `seo.region` 한 줄 | **서비스 지역 섹션 한 칸** (짙은 띠 + CTA) |
| 데스크톱 문의 | 오른쪽 세로 상담 레일 | **없음** — 머리의 전화·견적이 그 몫 |
| 문의 폼 | 이름·연락처·종류·평형·내용 | **+ 현장 위치 · 희망일**, 옆에 "이 세 가지만 알려 주세요" |
| 기본 색 | 차콜 / 베이지 / 블랙 / 그린 | **sky(네이비·프레시) / mist(그레이)** |
| 본문 폭 | 1280px · airy | 1200px · regular (정보 밀도를 올림) |

시험 `test_the_two_masters_do_not_look_like_the_same_site` 가 이 차이를 지킵니다 —
머리 클래스 · 첫 화면 클래스 · 레일 유무 · 섹션 구성 · 첫 화면 높이가 모두 다른지 봅니다.

## 4. 섹션 차례

```
HEADER   지역 칩 · 전화번호 · 견적 버튼
HERO     무슨 업체 / 어느 지역 / 무슨 청소 / 어떻게 문의   ← 5초 안에 넷
약속     숫자 없는 신뢰 4칸
서비스   입주 · 이사 · 거주 · 상가  (각 카드에 포함 범위 체크리스트)
왜 우리  소개 글 + 요약 표
전·후    작업 전 / 작업 후 비교 손잡이            ← 이 마스터의 심장
사례     작업 사례 3열 격자
진행     상담 → 일정 확인 → 현장 방문 → 작업 → 검수
지역     짙은 띠 + 지역 칩 + CTA                  ← 중간 전환 자리
후기     받은 후기만
질문     FAQ 아코디언
견적     폼 + "이 세 가지만" + 연락처
FOOTER   (좁은 화면) 전화 · 카카오톡 · 견적 고정 바
```

재료가 없는 칸은 **비워 두지 않고 통째로 뺍니다.** 후기가 없으면 후기 섹션이 없고,
서비스 지역이 없으면 지역 섹션이 없습니다. 무엇이 빠졌는지는 `납품메모.md` 에 적힙니다.

## 5. 데이터가 어디로 가는가

| siteConfig | 화면 |
| --- | --- |
| `company.name` · `tagline` · `description` · `owner` | 머리 · 첫 화면 · 왜 우리 · 바닥 |
| `hero.headline` · `subline` · `image` · `badges[]` | 첫 화면 |
| `strengths[]` (`name` + `설명`) | 약속 4칸 — **`숫자`·`단위`는 쓰지 않습니다** |
| `services[]` (`name` · `설명` · `사진` · `항목[]` · `가격`) | 서비스 카드 · 첫 화면 칩 · 견적 폼 선택지 |
| `about.문단[]` · `정보[]` · `사진` · `맺음` | 왜 우리 |
| `projects[]` 중 `작업전`+`작업후` 둘 다 있는 것 | **작업 전·후 비교** |
| `projects[]` 중 나머지 | 작업 사례 격자 |
| `process[]` | 진행 |
| `contact.서비스지역[]` · `지역안내` | 서비스 지역 섹션 · 머리 칩 · 첫 화면 · 바닥 |
| `contact.phone` · `kakao` · `hours` · `address` · `지도` | 머리 · 견적 · 바닥 · 하단 바 |
| `reviews[]` | 후기 (`별점` 을 안 주면 별을 그리지 않습니다) |
| `faq[]` | 질문 |
| `seo.*` | `<title>` · 설명 · 공유 이미지 · 구조화 데이터 |
| `theme.preset` | `sky` · `mist` · 그 밖의 기존 프리셋 |
| `layout.hero_align` | 첫 화면 `left` / `center` |

**규격은 그대로입니다.** 최상단 칸을 하나도 늘리지 않았습니다.
늘린 것은 기존 블록 안의 선택 칸 넷뿐입니다 — `projects[].before`/`after`,
`contact.areas[]`/`area_note`. 옛 주문서는 그대로 지어집니다
(`test_the_new_fields_are_optional` 이 지킵니다).

## 6. 관리자 웹에서 고객이 바꿀 칸

앞으로 만들 관리자 화면에서 **고객마다 갈아 끼우는 것**은 이것뿐입니다.

1. 상호 · 한 줄 소개 · 소개 글 · 대표
2. 전화 · 카카오톡 · 주소 · 영업시간 · 지도 링크
3. **서비스 지역** (여러 줄) · 지역 안내 한 줄
4. 서비스 4~6개 — 이름 · 설명 · 포함 범위 · 가격 표기
5. 작업 전·후 3~5세트 — 제목 · 분류 · 위치 · 평형 · 전 사진 · 후 사진
6. 작업 사례 6~10건 — 제목 · 분류 · 위치 · 사진
7. 진행 순서 5칸
8. 후기 (받은 것만)
9. FAQ
10. 색 버전 (`sky` · `mist` …) · 첫 화면 정렬

## 7. 고객에게 받을 사진

| 자리 | 장수 | 무엇을 |
| --- | --- | --- |
| 첫 화면 | 1장 | 청소가 끝난 밝은 공간, 또는 작업 중 현장. 가로로 넓은 것 |
| 작업 전·후 | **3~5세트 (6~10장)** | **같은 자리를 같은 각도에서.** 이게 안 맞으면 비교가 안 됩니다 |
| 서비스 | 4장 | 서비스마다 한 장. 작업 장면이면 더 좋습니다 |
| 작업 사례 | 6~10장 | 끝난 현장. 세로·가로 섞여도 됩니다 |
| 업체 소개 | 1~2장 | 장비·차량·팀. 없으면 뺍니다 |

**현장에서 알려드릴 말:** 전·후는 **찍는 위치를 표시해 두고** 작업 전에 먼저 한 장,
끝나고 같은 자리에서 한 장. 휴대폰 사진이면 충분합니다. 세로 사진, 어두운 사진,
해상도 낮은 사진도 그대로 받습니다 — 공장이 역할별 크기로 줄이고 WebP 로 바꿉니다
(작은 사진을 억지로 키우지는 않습니다).

지금 견본에 들어 있는 그림은 **저작권 문제가 없도록 직접 그린 SVG** 입니다
(`tools/make_cleaning_photos.py`). 스톡 사진은 라이선스를 확실히 확인할 수 없어
내려받지 않았습니다. 납품할 때 고객 사진으로 전부 바꿉니다.

## 8. 갈래 (variation)

지금 있는 것만 적습니다. 더 만들지 않았습니다 — **팔 수 있는 한 벌이 먼저**입니다.

| 칸 | 값 | 기본 |
| --- | --- | --- |
| `theme.preset` | `sky` · `mist` (+ 기존 charcoal · beige · black · green) | `sky` |
| `layout.hero_align` | `left` · `center` | `left` |

전·후 배치(split / grid)와 서비스 배치(cards / list)는 **아직 만들지 않았습니다.**
두 번째 청소 고객을 받을 때 실제로 필요하면 그때 늘립니다.

## 9. 검사

`tests/test_master_cleaning.py` 35건 + `tests/test_visual_qa.py` 의 청소 편 11건.

- 열한 섹션이 모두 서는가 · 빠진 재료가 없는가 · 100KB 대인가
- 전·후 짝이 슬라이더가 되는가 / 한 장만 와도 버티는가 / 짝이 없으면 섹션이 빠지는가
- 같은 사례가 비교와 사례 목록에 **두 번 나오지 않는가**
- 서비스 지역이 세 자리에 있는가 · 여덟 곳이어도 안 깨지는가 · 없으면 빠지는가
- **주지 않은 숫자를 세우지 않는가** (`숫자: 9,999` 를 넣어도 화면에 안 나옴)
- 받는 곳 없는 폼이 보낸 척하지 않는가 · `form_action` 을 주면 안내가 꺼지는가
- 서비스 1 / 3 / 8 / 12개 · 사례 0 / 1 / 10건 · 후기 0 · 질문 0 · 사진 0
- 긴 상호 · 긴 첫 화면 문구
- 카카오톡 없음 / 전화 없음 → 하단 바가 2칸으로 줄고 주 버튼이 바뀌는가
- 규격 호환 — 새 칸이 선택인가, 옛 주문서가 그대로 지어지는가
- **고객 사진**: 세로 900×1600 · 가로 2400×800 · 저해상도 320×240 · 어두운 사진을
  넣어도 경고 없이 WebP 로 바뀌고 역할별 최대폭을 넘지 않는가, 작은 것을 키우지 않는가
- 브라우저 1440 / 768 / 375 — 가로 스크롤 0 · 콘솔 오류 0 · 깨진 사진 0 ·
  비교 손잡이가 실제로 움직이는가 · 하단 바가 손끝에 닿는가
- **두 마스터가 같은 사이트로 보이지 않는가**

## 10. 아직 없는 것

- 가격표 섹션 — 청소는 현장마다 다르므로 V1 에서는 넣지 않았습니다.
  고객이 평형별 가격표를 주면 `services[].가격` 에 적히고, 표가 필요해지면 그때 만듭니다.
- 전·후 배치 갈래, 서비스 배치 갈래
- 문의 폼을 실제로 받는 곳 — `--form-action` 으로 Formspree 같은 주소를 꽂아야 합니다.
  안 꽂으면 손님에게 전화·카카오톡으로 안내합니다(설정 이야기는 하지 않습니다).

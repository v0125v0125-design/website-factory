# 판매 홈페이지 (storefront/)

우리 상품을 파는 원페이지입니다. **고객에게 납품할 홈페이지를 찍는 `factory/` 와는
완전히 다른 물건**입니다. 둘이 나눠 쓰는 것은 사진 최적화(`factory.images`) 하나뿐입니다.

```
storefront/
  storefront.json          글·값·가격·FAQ 가 전부 여기 있습니다
  build.py                 이 한 장을 정적 사이트로 굽습니다
  templates/index.html     화면
  templates/styles.css.j2  색은 storefront.json 의 theme 에서만 옵니다
  assets/samples/          샘플 화면 사진 (실제로 지은 사이트를 찍은 것)
```

## 짓기

```
python storefront/build.py _site/store        # 혼자 짓기
python tools/build_previews.py _site          # 미리보기 묶음에 /store/ 로 같이 실린다
python tools/shoot_sample_thumbs.py           # 샘플 사진을 다시 찍는다 (Playwright 필요)
```

미리보기 묶음에 실을 때는 `PREVIEW_BASE` 를 따라 주소가 바뀝니다. 샘플 링크와
canonical 이 모두 그 주소로 갑니다.

## 고칠 때는 여기만

| 바꾸고 싶은 것 | 고칠 자리 |
| --- | --- |
| 브랜드명 | `brand.name` · `brand.shortName` · **`seo.title` 도 같이** |
| 연락처 | `brand.contact` (phone · kakao · email) |
| 사업자 정보 | `brand.legal` — 비어 있으면 푸터에 아예 안 나옵니다 |
| 색 | `theme` |
| 가격·포함 범위 | `products.items` |
| 샘플 | `samples.items` — `status` 가 `available` 인 것만 링크가 걸립니다 |
| FAQ·문의 항목 | `faq.items` · `order.fields` · `quote.fields` · `advice.fields` |
| 검색 노출 | `seo.noindex` — `false` 로 바꾸면 robots 가 열리고 sitemap 이 나갑니다 |

## 못 박아 둔 세 가지

이 셋은 `tests/test_storefront.py` 가 지킵니다. 고치면 빨간불이 납니다.

1. **없는 후기와 없는 숫자를 만들지 않습니다.** 후기·평점·누적 고객 수는 화면에도
   구조화 데이터에도 넣지 않습니다. 팔 실적이 쌓이면 그때 넣습니다.
2. **보낸 척하지 않습니다.** 지금은 받는 서버가 없습니다. 문의 폼은 작성한 내용을
   사람이 읽을 수 있는 글로 만들어 클립보드에 복사해 주고, **전송되지 않았다고
   그대로 적습니다.** `brand.contact` 를 채우면 그 창구 버튼이 결과 칸에 함께 뜹니다.
3. **샘플을 '고객 제작 사례'라 부르지 않습니다.** 셋 다 저희가 만든 **디자인 샘플**이고
   가상 업체 자료로 채웠습니다. 실제 고객사·납품 실적으로 표현하지 않습니다.
4. **스스로를 자동생성·공장형이라 부르지 않습니다.** 파는 말은
   "디자인 선택형 홈페이지 제작"입니다. 대신 `scope` 블록에서 **포함되지 않는 것**을
   먼저 적습니다 — 레이아웃 변경·새 섹션·페이지 추가는 PREMIUM 입니다.
